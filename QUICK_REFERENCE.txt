┌─ KEY CONCEPT: TIME-VARYING TRANSFORMATIONS ──────────────────────────────┐
│                                                                            │
│  WRONG (Constant):                                                        │
│  ┌─────────────────────────────────────────────────────────────┐        │
│  │ for all t: b_FR2 = [0.5, 0, ...]                            │        │
│  │ Problem: Entire trajectory shifted uniformly                │        │
│  │ Result: Initial position CHANGED ❌                          │        │
│  └─────────────────────────────────────────────────────────────┘        │
│                                                                            │
│  CORRECT (Time-Varying):                                                 │
│  ┌─────────────────────────────────────────────────────────────┐        │
│  │ for t in [0,1]: b_FR2(t) = [d_min + (d_max - d_min)*t, 0]  │        │
│  │ Benefit: Smooth adaptation over time                        │        │
│  │ Result: Initial position PRESERVED ✓                        │        │
│  │         Endpoint adapted to target ✓                        │        │
│  └─────────────────────────────────────────────────────────────┘        │
│                                                                            │
└──────────────────────────────────────────────────────────────────────────┘

┌─ THREE REFERENCE FRAMES ─────────────────────────────────────────────────┐
│                                                                            │
│  FR1: Hip-centered frame (body reference)                                │
│       Transform: IDENTITY (no change)                                    │
│       A₁ = I, b₁ = 0                                                     │
│                                                                            │
│  FR2: Right foot target frame (ADAPTED!)                                 │
│       Transform: TIME-VARYING                                            │
│       A₂(t) = rotation matrix, b₂(t) = translation vector                │
│                                                                            │
│  FR3: Left foot target frame                                             │
│       Transform: IDENTITY (no change)                                    │
│       A₃ = I, b₃ = 0                                                     │
│                                                                            │
└──────────────────────────────────────────────────────────────────────────┘

┌─ 11 DIMENSIONS ──────────────────────────────────────────────────────────┐

│  [2-3]:  Right ankle velocity (vx, vy)                                   │
│  [4]:    Right ankle angle                                               │
│  [5-6]:  Left ankle position (x, y)                                      │

┌─ EXOSKELETON INTEGRATION ────────────────────────────────────────────────┐
│                                                                            │
│  Real-Time Control Loop:                                                 │
│                                                                            │
│  1. Sense: Read IMU + force sensors from crutches                        │
│  2. Estimate: Calculate desired foot endpoint from crutch data           │
│  3. Adapt: Create time-varying transformation to endpoint                │
│  4. Generate: Run GMR with adapted frames                                │
│  5. Control: Send joint commands to exoskeleton actuators                │
│  6. Repeat: Loop at 100-1000 Hz                                          │
│                                                                            │
│  Key Equation:                                                            │
│  b_FR2(t, target) = (target - baseline_endpoint) × phase(t)              │
│                                                                            │
